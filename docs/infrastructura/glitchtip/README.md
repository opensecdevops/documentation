# GlitchTip

GlitchTip es una herramienta de monitorización de errores orientada a identificar y registrar errores que ocurren durante la ejecución de aplicaciones. Su objetivo es facilitar la mejora de la calidad y confiabilidad del software. Entre sus principales características se encuentran:

- **Seguimiento de errores:** GlitchTip proporciona información detallada sobre cada error, incluyendo la ubicación, el tipo de error y la pila de llamadas.
- **Monitoreo del rendimiento:** Permite analizar el rendimiento de la aplicación, identificando posibles cuellos de botella y áreas de mejora.
- **Monitoreo del tiempo de actividad:** Puede realizar comprobaciones periódicas al sitio y notificar mediante correo electrónico o webhook si detecta que no está disponible.
- **Compatibilidad con SDK de Sentry:** GlitchTip utiliza el SDK de cliente Sentry, que es de código abierto. Si ya se utiliza Sentry en los proyectos, solo es necesario cambiar la URL de destino para los reportes.
