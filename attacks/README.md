# Introducción

En este manual se abordan los conceptos básicos de seguridad web utilizando la plataforma [DVWA](https://github.com/digininja/DVWA) con fines prácticos.

DVWA es una plataforma vulnerable escrita en PHP/MySQL, estructurada en torno a diferentes vulnerabilidades existentes, que facilita el aprendizaje tanto para profesionales de la seguridad como para desarrolladores interesados en comprender cómo se pueden explotar y proteger aplicaciones web.

## Descargo de responsabilidad

El contenido de este manual tiene fines educativos y está orientado a la mejora de conocimientos y prácticas de desarrollo seguro. El uso inadecuado de la información aquí presentada es responsabilidad exclusiva de quien la utilice.

En ningún caso el material incluido está destinado a fines ilícitos; su propósito es contribuir al aprendizaje y fortalecimiento de la seguridad en aplicaciones web.
