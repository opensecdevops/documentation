# OSDO CLI - Infrastructure Tool

[![Go Version](https://img.shields.io/badge/Go-1.21+-blue.svg)](https://golang.org)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Build Status](https://img.shields.io/badge/Build-Passing-brightgreen.svg)](https://github.com/osdo/osdo-infra-cli)

> **OSDO CLI** es una herramienta multiplataforma para desplegar y gestionar el stack completo de herramientas DevSecOps de OSDO de manera unificada y eficiente.
Con dicho CLI puedes desplegar en un solo comando todo el stack de herramientas DevSecOps, incluyendo CI/CD, seguridad, monitoreo y más, en múltiples plataformas como Kubernetes, K3s, Kind, Docker Swarm, Docker Compose y Helm.

## 🚀 Características Principales

- **🎯 Multiplataforma**: Soporta Kubernetes, K3s, Kind, Docker Swarm, Docker Compose y Helm
- **🧩 19+ Componentes**: Stack completo de DevSecOps incluyendo CI/CD, seguridad, monitoreo y más
- **⚡ Despliegue Simplificado**: Un solo comando para desplegar infrastructure completa
- **🎛️ Modo Interactivo**: Selección visual de componentes y configuraciones
- **📦 Presets Inteligentes**: Configuraciones predefinidas para desarrollo, staging y producción
- **🔧 Altamente Configurable**: Archivos YAML para configuraciones complejas
- **🛡️ Seguridad Integrada**: Herramientas de análisis y políticas incluidas por defecto
